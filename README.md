# Dystos

Dystos is a modern programming language with a focus on learnability, safety, and clarity.

## Structure

- compiler/ - Dystos compiler (lexer, parser, semantic analysis, interpreter)
- content/ - Learning content (Markdown + exercises)
- site/ - Static website (React + TypeScript)
- apps/android/ - Android application
- services/playground/ - Online playground service
- tools/build-content/ - Content build tool
- deploy/ - Deployment configuration
- docs/ - Documentation
